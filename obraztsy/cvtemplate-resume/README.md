## 🚀 How to Use This Template

### For Melvin (Original Owner)
1. Fork or clone this repo
2. Update content in HTML files (already filled with your data)
3. Replace `assets/images/personal.png` if you want to change your photo
4. Deploy to GitHub Pages

### For Others (Reuse as Template)
1. **Fork** this repository or download as ZIP
2. Replace the following placeholders with your own data:
   - `Melvin Cavellino` → Your Name
   - `Supervisor Legal Process Documentation` → Your Role
   - `Samarinda, Kalimantan Timur` → Your Location
   - Email, LinkedIn, WhatsApp → Your contacts
   - Work experience → Your experience
   - Skills → Your skills
3. Replace `assets/images/personal.png` with your own photo
4. Update colors in `assets/css/style.css` if you want a different theme
5. Deploy to GitHub Pages or any static host

## 📤 Deploy to GitHub Pages

### Step 1: Create Repository
1. Go to [github.com/new](https://github.com/new)
2. Fill in the details (see recommendations below)
3. Click **Create repository**

### Step 2: Push Code
```bash
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git branch -M main
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. Go to repository **Settings** → **Pages**
2. Under **Source**, select **Deploy from a branch**
3. Select **main** branch and **/(root)** folder
4. Click **Save**
5. Your site will be live at: `https://your-username.github.io/repo-name/`
