# 🥐 Bakary Website

## 📌 Overview
Bakary is a modern and fully responsive bakery website built using HTML and CSS.  
The project focuses on clean UI design, smooth layout structure, and a visually appealing user experience.

---

## ✨ Features
- Responsive design for all screen sizes
- Clean and modern user interface
- Well-structured layout using semantic HTML
- Stylish and elegant CSS design
- Simple and user-friendly navigation

---

## 🛠️ Technologies Used
- HTML5
- CSS3

---

## 🎯 Purpose
This project was built to practice frontend development skills, improve UI design techniques, and strengthen understanding of responsive web design using only HTML and CSS.
