# Changelog

## 1.0.0 — 2026-08-09

### Added
- Initial LaunchForge Bootstrap landing-page template.
- Responsive navigation, hero, process, feature, service, security, CTA, and footer sections.
- Bootstrap 5 and Bootstrap Icons CDN dependencies.

### Fixed
- Invalid color declaration missing `#`.
- Global `.btn:hover` override that affected every Bootstrap button.
- Global `.rounded-circle` override that conflicted with Bootstrap utilities.
- Incorrect `Safty` spelling and anchor.
- Uppercase `<Div>` elements.
- Nested `<footer>` elements.
- Script placement outside the body.
- Hard-coded card image heights moved into a reusable class.
- Mobile behavior for the CTA/background and phone mockup.
